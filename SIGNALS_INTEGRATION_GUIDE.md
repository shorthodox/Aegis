# Real-time Signals Integration Guide

## System Overview
The AEGIS dashboard now fetches and displays real-time trading signals generated by the Python backend engine. Here's how everything is connected:

## Architecture

### Backend (main.py)
```
┌─────────────────────────────────────────────────┐
│ LiveEngine (scripts/live_engine.py)             │
│ - Generates signals from 58 crypto pairs        │
│ - Updates every 1 second                        │
│ - Stores in LIVE_STATE.data["signals"]          │
└─────────────────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────┐
│ run_engine_background() - Background Task       │
│ - Writes to web/src/data/live_signals.json      │
│ - Updates LIVE_STATE every second               │
└─────────────────────────────────────────────────┘
                        │
         ┌──────────────┼──────────────┐
         ▼              ▼              ▼
    [WebSocket]   [Public API]   [JSON File]
      /ws/      /api/public/   live_signals.json
    /dashboard   /signals
```

### Frontend (Browser)
```
┌──────────────────────────────────────────────────┐
│ dashboard.html                                   │
│ - Loads trial-countdown.js                       │
│ - Loads app.js                                   │
│ - Contains signal-grid div for display           │
└──────────────────────────────────────────────────┘
         │                    │
         ▼                    ▼
    [trial-countdown.js]  [app.js]
    - Shows trial timer      - Initializes SignalStore
    - Monitors warmup        - Sets up RenderEngine
                             - Connects WebSocket
                             - Listens for updates
         │                    │
         └────────┬───────────┘
                  ▼
      ┌─────────────────────────────────┐
      │ SignalStore (signalStore.js)    │
      │ - Auto-fetches every 2 seconds  │
      │ - From /api/public/signals      │
      │ - Caches signal objects         │
      │ - Notifies listeners on change  │
      └─────────────────────────────────┘
                  │
                  ▼
      ┌─────────────────────────────────┐
      │ RenderEngine (renderEngine.js)  │
      │ - Renders signals to DOM        │
      │ - Updates signal-grid           │
      │ - Handles user interactions     │
      └─────────────────────────────────┘
```

## Signal Flow

### 1. Signal Generation (Backend)
```python
# main.py - Background Task
async def update_state():
    while True:
        LIVE_STATE.data["signals"] = engine.last_signals.copy()
        
        # Write to JSON file
        with open('web/src/data/live_signals.json', 'w') as sf:
            json.dump(LIVE_STATE.data.get('signals', {}), sf)
        
        await asyncio.sleep(1)
```

### 3. Frontend Signal Fetching (Client)

```javascript
// signalStore.js - Auto-fetch every 2 seconds
async fetchLiveSignals() {
    const response = await fetch('/api/public/signals');
    const data = await response.json();
    this.updateMultiple(data.signals);
    // Notify warmup status
    const event = new CustomEvent('warmupUpdate', { 
        detail: { warmup: data.warmup } 
    });
    document.dispatchEvent(event);
}
```

## How to Use

### Starting the Server
```bash
# Activate Python environment
source .venv/bin/activate

# Run main.py
python main.py

# Server starts on http://localhost:8000
# Engine starts generating signals in background
# Writes to web/src/data/live_signals.json every second
```

### Accessing Dashboard
```
1. Open http://localhost:8000/dashboard
2. Dashboard loads dashboard.html
3. trial-countdown.js and app.js initialize
4. SignalStore starts auto-fetching signals every 2 seconds
5. RenderEngine displays signals in real-time
6. Warmup progress appears in sidebar
7. WebSocket connects for additional real-time data
```

### Signal Data Structure
Each signal contains:
```javascript
{
    pair: "BTC/USDT",              // Trading pair
    signal: "BUY|SELL|WAITING",    // Signal type
    entry: 45000.0,                // Entry price
    sl: 44500.0,                   // Stop loss
    tp: 46500.0,                   // Take profit
    status: "OPEN|CLOSED",         // Signal status
    confidence: 0.85,              // AI probability (0-1)
    atr: 250.0,                    // Average true range
    rr: 2.0,                       // Risk/reward ratio
    time: "2026-05-10T12:30:00",   // Signal time
    timeframe: "15m"               // Timeframe (from localStorage)
}
```

## Performance Notes

- **Signal Fetch**: Every 2 seconds (configurable in signalStore.js)
- **Engine Update**: Every 1 second (configured in main.py)
- **WebSocket Update**: Every 1 second (from main.py)
- **JSON File Write**: Every 1 second (background task)

For faster updates, reduce the fetch interval in signalStore.js:
```javascript
this.fetchInterval = setInterval(() => this.fetchLiveSignals(), 1000); // 1 second
```
