# Workspace Guidelines & Rules — Aegis AI Signal Bot

## 1. User Doubt Confirmation & Pre-Edit Protocol
- **Confirm Right vs. Wrong**: Whenever the user expresses a doubt, question, hypothesis, or observation regarding market mechanics, engine gating, signal generation, or UI behavior, ALWAYS explicitly state whether their doubt/hypothesis is **RIGHT** or **WRONG**, accompanied by clear technical reasoning.
- **Explain Before Editing**: BEFORE making any code edits or file modifications, ALWAYS explain the analysis, confirm if the user's doubt is right or wrong, and outline the exact proposed changes.
